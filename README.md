# K뷰티 커리어스캔 (K-Beauty CareerScan)

뷰티 구직자를 위한 무료 서비스 — 감사보고서 실데이터로 K뷰티 61개사의 취업 체력(성장·수익·안정·연봉)을 점수화.

**사이트**: https://jaehoonlee-constant.github.io/kbeauty-careerscan/

- 데이터: 금융감독원 전자공시(DART) 감사보고서 2022–2025, 국민연금공단 사업장 공시
- 산식·한계: [방법론](https://jaehoonlee-constant.github.io/kbeauty-careerscan/methodology.html)
- 기업 정정 요청·데이터 제보: 이 저장소 Issues로 접수
